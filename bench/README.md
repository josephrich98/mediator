# Benchmark harness

`run.js` starts N headless Claude Code agents (`claude -p`, Sonnet 5.5 by default, `--permission-mode acceptEdits`, isolated `CLAUDE_CONFIG_DIR`, project settings only) five seconds apart in one fresh copy of `fixture/` (a 3-file todo CLI with tests), waits for all of them, runs the scenario's acceptance checker, and parses each agent's `stream-json` transcript for cost, tokens, turns, tool errors, mom blocks, and how often an agent saw a failing `npm test`.

```
node bench/run.js --condition baseline|mom-advisory|mom-strict \
  [--trials 3] [--model claude-sonnet-5-5] [--max-turns 100] [--stagger 5] \
  [--tasks bench/tasks-long.json --check bench/check-long.js --tag long]
node bench/report.js bench/results-<tag>.jsonl
```

Scenarios:

| tag | agents | tasks | checker |
|---|---|---|---|
| (default) `tasks.json` | 3 | async Store refactor; priority flag + filter; due date + `--overdue` | `check.js` (23 checks) |
| `hard` `tasks-hard.json` | 3 | CJS→ESM migration; `text`→`title` rename with legacy migration; priority + sort | `check-hard.js` (23 checks) |
| `long` `tasks-long.json` | 3 | each agent chains two of the above (ESM→async, rename→due, priority→`--json`+`edit`) | `check-long.js` (32 checks) |

Results (n = 3 each, 2026-10-30, Sonnet 5.5):

**long**

| Metric | baseline | mom-advisory | mom-strict |
|---|---|---|---|
| Wall-clock | 81s ± 6 | 114s ± 14 | 125s ± 13 |
| Cost (USD) | 0.54 ± 0.08 | 0.47 ± 0.12 | 0.45 ± 0.05 |
| Output tokens | 23428 ± 1738 | 19929 ± 4564 | 21199 ± 2407 |
| Input tokens (incl. cache) | 1197k | 1093k | 896k |
| Assistant turns | 37.7 | 54.0 | 43.7 |
| Red test runs seen | 7.0 ± 6.2 | 1.0 ± 1.0 | 2.7 ± 2.9 |
| Acceptance (of 32) | 32.0 | 32.0 | 32.0 |

**default (medium)** — baseline 53s / $0.28 / 23/23; mom-strict 144s ± 80 / $0.41 / 23/23; the v0.1 strict run that deadlocked was aborted after 7 minutes (one completed v0.1 trial: 105s / $0.41 / 23/23).

**hard** — baseline 52s / $0.24 / 22.7/23; mom-strict 118s ± 65 / $0.44 / 22.7/23 (one trial hit 16 blocks and 102 turns).

Caveats: n = 3, one model, one tiny repo, tasks that finish in about a minute. The raw per-trial data is in `results-*.jsonl`; per-trial transcripts are not committed (`runs/` is git-ignored) but are regenerated by `run.js`.
